# Changelog

## 0.1.0

First release.

- Named guests (username, email, password) and voucher series (prefix + number),
  valid for a number of days: OpenWISP deactivates them at 00:01 after the last day.
- Tickets on A4 sheets (10 per page), 58/80 mm receipts or labels of any size,
  with logo, venue name, website, email, phone, Wi-Fi network and QR code.
- Print, save as PDF or copy the text to send it.
- List of the accounts created on this computer: reprint, deactivate now,
  refresh status from the server.
- Superusers choose the organization, operators work only on their own.
- Italian and English interface.
